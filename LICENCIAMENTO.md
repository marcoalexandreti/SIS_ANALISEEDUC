# Publicar a licença no GitHub

Este pacote contém uma licença específica em português para o SIS_ANALISEEDUC. Não é uma licença MIT, GPL, Creative Commons ou PolyForm. As permissões e restrições aplicáveis são as de LICENSE.md.

## Regras principais

- Usar, estudar, copiar e modificar o código para fins não comerciais: permitido.
- Redistribuir gratuitamente o código original ou modificado para fins não comerciais: permitido, com preservação dos créditos, avisos e licença.
- Manter alterações internas não comerciais sem publicá-las: permitido.
- Vender, revender, cobrar assinatura ou oferecer hospedagem comercial do software: exige autorização escrita separada.
- Incorporar o código em produto ou serviço comercial: exige autorização escrita separada.
- Remover os créditos ou apresentar o código original como autoria exclusiva de outra pessoa: não permitido.

A identificação dos titulares não foi presumida nesta preparação. Aplique esta licença somente ao código sobre o qual você ou a instituição responsável tenham direitos para licenciar. Preserve os avisos de autoria já existentes e não substitua as licenças das bibliotecas de terceiros.

## Envio ao repositório

1. Extraia o ZIP.
2. Envie LICENSE.md e NOTICE.txt para a raiz do repositório, na mesma pasta do README.md.
3. Substitua a seção antiga de licenciamento do README.md pelo conteúdo de TRECHO_README.md.
4. Revise os avisos de titularidade e autoria existentes no código e registre as alterações no GitHub.

LICENCIAMENTO.md é um guia e pode ser publicado na raiz se desejar. TRECHO_README.md é apenas o texto pronto para inserir no README, não precisa ser publicado separadamente.

A licença não concede direitos sobre marcas e brasões nem autoriza divulgar dados pessoais. Não houve alteração ou publicação no repositório remoto nesta preparação.
